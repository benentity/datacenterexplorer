# Data Center Explorer

An interactive 3D model of a data center. It shows 60 product categories in 4 groups (Servers, Network, Power Supply, Cooling), the areas where they sit, and 200 component suppliers with their stock tickers.

Open the live page: https://benentity.github.io/datacenterexplorer/

The whole site is one self-contained file, `index.html`. The 3D engine is three.js r147 (MIT licence), included inside the file.
